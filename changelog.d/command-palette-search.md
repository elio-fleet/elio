### Added

- **⌘K finds CVEs, packages and notes** while you type: a CVE id (or a part of it, `CVE-2024-91`, `2024-91`) lists the fleet's CVEs with their number of servers and opens the CVE page; a package name lists the matching packages, the exact name first; the server notes whose text matches open that server's journal. A last entry searches the text in the journal.
- **Actions in ⌘K** for operators and admins: "Inventory every server" (after a confirmation giving the number of servers) and "Inventory <server>" (type `inventory web`), followed on the runs page.
- **Recent entries first in ⌘K**: the pages, servers and tabs opened lately from it come first, under "Recent" (remembered in the browser only).

### Fixed

- The French placeholder of the ⌘K search read "key"; it now hints at what can be searched.
