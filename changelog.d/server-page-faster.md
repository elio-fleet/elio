### Changed

- **Server page**: a port check or SSH login from the last five minutes (a check, an inventory, a key scan) is shown as is instead of being run again on every visit; the refresh buttons still check at once. A failed SSH login is always checked again.
- **Server page**: a link to a server opens the tab you last opened on it (remembered in this browser for the 50 most recent servers); the *Overview* tab takes you back.
