### Added

- **Remove a keyring key from every server** in one action (someone leaves, a lost key): its menu on the key page removes it from every account where the last key reads saw it, a few servers at a time, with the outcome of each account.
- **Retry only the failures** after adding a key to several servers or removing it everywhere: the results come with a button that runs the action again on the failed servers, with the same duration and account.
- The server picker of the key page says how many servers are checked, and each group button how many servers it has.
