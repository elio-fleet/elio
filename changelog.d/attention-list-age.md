### Added

- **"To handle" says since when**: each problem of a server, on the overview and on the server page, shows when it started (read from the journal: unreachable, key refused, health and Docker alerts), with the exact date as tooltip.

### Changed

- **"To handle" on the overview** shows the 8 most serious items first; "See all" lists the others.
- **Vulnerability actions open the fix commands**: a server's vulnerability reason, and the fleet item when a single server is concerned, open its packages to update, each one with the command to copy.
