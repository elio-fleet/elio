### Added

- **Server journal**: two more filters, *Accesses and keys* (keys given, temporary accesses extended or expired, keys removed, unknown or vanished keys, SSH access lost) and *Deployments* (shown once the server had a Coolify deployment), next to *Notes* and *Events*.
- **Server journal search**: a text (notes, authors, servers, keys, accounts, kinds of event) and a period, like the fleet journal, kept in the address with the filter.
- **Server journal export** as CSV or JSON (its actions menu), with the filter and the search of the tab: its events and its notes on the same columns as the journal export (a note's kind is `server_note`, its Markdown is the summary, its link opens it on the server page).
